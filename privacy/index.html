PRIVACY POLICY

What happens behind the glass.

This policy explains the limited technical processing involved when you visit Choicer Voicer Studio and use its embedded services. Last updated: August 17, 2026.

Information processed when you visit

Our hosting provider may process standard request information such as IP address, browser type, device type, requested URL, timestamps, and error or security logs. We do not ask visitors to create an account on the current site and we do not operate a user profile database.

Audience measurement

We load one analytics script from https://data.1back.link/js/app.js using the site domain choicervoicer.site and the endpoint https://data.1back.link/api/send. In addition to aggregate visits, we record limited interaction events such as navigation and game-card clicks, game start and completion, score and round numbers, Persona completion and sharing method, tool activation, coarse media type and size ranges, setting changes, microphone permission success or failure, advertising-slot loading, scroll-depth milestones, and 30- or 120-second engagement milestones. Event properties do not include microphone audio, recordings, player names, filenames, search text, captions, Persona answer text, or imported media. The provider may receive technical request data necessary to deliver the script and record events. Browser privacy controls, content blockers, or script blocking can prevent this measurement.

Advertising

We use advertising scripts served through effectivecpmnetwork.com and highperformanceformat.com. Advertising providers may process IP address, browser and device information, approximate location, referring pages, ad impressions, clicks, cookies, or similar identifiers to deliver, limit, measure, and protect advertisements. Desktop visitors may see a native advertising block, mobile visitors may see a 320 by 50 banner, and a Social Bar format may load only after a visitor scrolls away from the game area. Advertising can be blocked by browser privacy controls or content blockers.

Game and video embeds

The game iframe is served by s.templeofthejackal.com. Gameplay videos are served by YouTube. When you choose to start the game or load a video, those third parties may receive technical data and may use their own cookies, local storage, logs, or account signals under their policies. We do not control their processing.

Microphone permission and game results

The embedded game may request microphone access because voice is its central input. Permission is controlled by your browser and operating system. After a scored round, the game can send the score, round details, and that round's recorded take from the iframe to this page. The parent page converts supported raw audio into a temporary WAV object URL so you can play or download it. The take stays in the active browser tab, is not uploaded by our application, is not placed in analytics, and is discarded when it is replaced or the page reloads. A completed match summary and Persona-reading counts may be stored in your browser's local storage so the result can appear on a share card; you can remove them by clearing this site's browser data.

Local creation tools

The Dub Studio, Clip Maker, party board, Pack Library filters, and microphone test primarily use browser-side state. Selected video files are opened as local browser object URLs, and Pack waveform analysis remains on the device. Dub export draws the selected video, Hook, and optional caption into a browser Canvas and uses MediaRecorder to create a temporary WebM; the source and export are not uploaded by this workflow. Native file sharing or opening a social platform is initiated only when you press the related button, and those platforms then process the file under their own policies. Microphone-test audio is analyzed for a live level meter and is not recorded or saved. Media is not uploaded merely because you select or preview it.

Local Whisper transcription

When you explicitly start Local processing in the Pack workbench, the browser downloads a multilingual Whisper ONNX model from Hugging Face and caches supported model files in browser storage. Hugging Face may receive technical request information such as your IP address, browser details, requested model files, and timestamps under its applicable policy. The selected video or audio, detected speech, timestamps, and editable transcript remain in the active browser and are not sent to Hugging Face, our server, OpenAI, or analytics by this feature. Compatible Chrome and Edge browsers may use WebGPU; other supported browsers fall back to WASM and CPU processing. Clearing browser site data may remove cached model files.

Planned AI tools

AI captions, audio cleanup, and other cloud assistance in Dub are not currently active. Selecting the planned option records only a controlled interest event so we can measure demand; the event does not contain your filename, media, caption, Hook, or other free-form text. If AI processing, accounts, or subscriptions are introduced later, this policy and the in-product notice will be updated before media is uploaded.

Planned cloud transcription

Cloud transcription in the Pack workbench is not currently active. Selecting its planned option records only a controlled interest event so we can measure demand; the event does not contain your filename, media, Pack name, transcript, or other free-form text. If cloud transcription, accounts, or subscriptions are introduced later, this policy and the in-product notice will be updated before media is uploaded.

Your choices

You can decline microphone access, stop the game, block third-party scripts, clear browser site data, use privacy settings, or leave the page. Some game functions will not work without microphone permission. For privacy questions, contact mooyuking@gmail.com.
