Where are Choicer Voicer dubs saved?

Understand the difference between game storage, browser files, and recordings you create.

Last verified: August 27, 2026
Import a recordingRead the steps ↓
01

Check the method you used

A browser screen recorder normally saves to the browser download location or asks where to place the file. Operating-system capture tools use their own Videos or Captures folder.

02

The parent site cannot inspect the game

The game runs in a cross-domain iframe. ChoicerVoicer.site cannot browse its internal files, scores, recording state, or storage unless the game explicitly sends a supported message.

03

Search safely

Check recent downloads and your capture tool settings before recording again. Do not install unknown file-finding utilities or upload private recordings merely to locate them.

04

Check browser downloads first

Open the browser download history and look for the time of the session. A browser recording or downloaded take normally appears in the configured Downloads folder unless the browser asked for another location. Search by recent date before searching the whole drive.

05

Check the capture tool

Windows Game Bar commonly uses Videos and Captures, while macOS screenshots and recordings usually use the destination selected in the Screenshot toolbar. OBS and other recorders have their own output path. Open the tool's settings instead of guessing from the game page.

06

Understand browser storage

A take kept inside the game may live in that game's browser storage rather than as a visible file. ChoicerVoicer.site cannot inspect a cross-domain iframe's private storage. Clearing site data, using a private window, or changing browsers can make locally retained state unavailable.

07

Preserve the next take

Before another session, choose a known recording folder, make a ten-second test, and confirm that the file plays. Rename finished takes with a date and scene name. Ask every performer before moving a recording into cloud storage or a social workflow.

08

Separate a downloadable file from browser state

A visible MP4, WebM, WAV, or audio file in Downloads can be copied and backed up. Browser storage is different: it belongs to a specific origin, browser profile, and device, and it may disappear after site-data cleanup or private browsing. The parent page cannot enumerate files held by the cross-domain game. Before clearing data, export anything the game explicitly allows you to download and keep the source Pack archives needed to reproduce the session.

09

Create a repeatable recording folder

Choose one folder for raw captures and a second for edited clips. Name files with date, game, Pack, and take number, such as 2026-08-27-backrooms-take-02.webm. Add a short text note for performers, consent, and edits when the recording may be shared. Test free disk space before a long session and move finished files to backup storage only after opening them successfully. This simple routine is safer than installing an unknown recovery tool after a browser tab has already been closed.
